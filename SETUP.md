# 🚀 Как установить GitHub Профиль

## Шаг 1: Создай репозиторий

1. Перейди на [github.com/new](https://github.com/new)
2. Создай репозиторий с именем **точно совпадающим** с твоим username: `wakaexe`
3. ✅ Отметь "Add a README file"

## Шаг 2: Загрузи файлы

Скопируй содержимое `README.md` в корень репозитория.

Загрузи папку `.github/workflows/snake.yml` для автоматической генерации змейки.

## Шаг 3: Включи GitHub Pages

1. Перейди в **Settings** → **Pages**
2. В **Source** выбери **Deploy from a branch**
3. В **Branch** выбери `output` (ветка создастся автоматически через ~15 минут)
4. Нажми **Save**

## Шаг 4: Настрой статистику (опционально)

### WakaTime
1. Зарегистрируйся на [wakatime.com](https://wakatime.com)
2. Установи плагин для своего редактора
3. Раскомментируй секцию WakaTime в README.md
4. Замени `USERNAME` на свой ник WakaTime

### Добавь свой активный проект
Замени `YOUR_REPO` в секции "Текущий проект" на название своего репозитория.

## Шаг 5: Обнови контакты

В README.md замени:
- `wakaexe@gmail.com` — на свой реальный email
- `linkedin.com/in/wakaexe` — на свой LinkedIn
- `discord.gg/wakaexe` — на свой Discord (если есть)
- `stackoverflow.com/users/wakaexe` — на свой профиль

## Готово! 🎉

Твой профиль обновится автоматически через несколько минут.
